# Benchmark and workflow figures

Figures used by the root `README.md` and by `docs/benchmark.md`. 
Captions, data definitions and the comparators are given in
[docs/benchmark.md](../../benchmark.md). Figures are PNG exports of the
reviewed benchmark analysis; the source tables and plotting scripts are held
by the Earlham Institute and are not part of this release.

| File | Used in | Content |
|---|---|---|

| `qc118_clade_guided_moselecta_vs_predictors_f1.png` | benchmark.md, Benchmark 1 | Paired difference in combined F1 between each predictor and clade-informed MoSelecta, 118 species |
| `five_species_annotation_workflows_combined_f1.png` | benchmark.md, Benchmark 2 | Combined F1 of practical annotation workflows and individual predictors on five species |
| `five_species_gene_sensitivity_precision.png` | benchmark.md, Benchmark 2 | Gene-level sensitivity against precision for the seven predictors and three MoSelecta workflows, five species |
| `moselecta_workflow_overview.png` | README (How MoSelecta works) | Workflow schematic following one synthetic locus through the 17 pipeline stages of the user guide |
